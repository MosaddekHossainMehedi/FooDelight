# 🍔 FooDelight

A clean, responsive front-end for a food ordering website — browse categories, view featured dishes, add items to a cart, and check out, all built with vanilla HTML, CSS, and JavaScript.

**Live Demo:** [foodielight.vercel.app](https://foodielight.vercel.app/) · [mosaddekhossainmehedi.github.io/FooDielight](https://mosaddekhossainmehedi.github.io/FooDielight/)

---

## ✨ Features

- **Multi-page layout** — Home, Menu, About, and Contact pages
- **Dynamic menu rendering** — food items rendered from a JS data set
- **Shopping cart** — add/remove items, live total, item count badge
- **Persistent cart** — cart state saved to `localStorage` across sessions
- **Checkout flow** — modal-based cart review and checkout
- **Fully responsive** — adapts cleanly across desktop, tablet, and mobile
- **Icon-based UI** — powered by Font Awesome

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 |
| Interactivity | JavaScript (Vanilla, ES6) |
| Icons | Font Awesome |
| Storage | Browser `localStorage` |
| Hosting | Vercel · GitHub Pages |

No frameworks, build tools, or dependencies — the site runs directly in the browser.

## 🚀 Getting Started

No build step required.

```bash
# Clone the repository
git clone https://github.com/MosaddekHossainMehedi/FooDielight.git

# Move into the project directory
cd FooDielight

# Open index.html directly in your browser,
# or serve it locally, e.g.:
npx serve .
```
